## What this teaches for motion-design reference copying
1. Coarse-to-fine IS the motion. Teardown should record a scale ladder, not just easing. Here the ladder is explicit and measurable: brush sizes 126, 69, 38, 21, 12, 7, 4, 3, with pass names Block-in / Form and color / Refinement / Fine details. A copy needs that ladder + pass boundaries, not a camera move.
2. Static-frame + progressive resolve is a copyable pattern. One fixed frame, one static reference on the right, image resolves in place. Our teardown needs a "progressive resolve" profile: start state (blank), intermediate mosaic state, end state (near-photo), and the size step at each stage.
3. Beware the blur-back test. By brush 3 the result is basically the reference photo again. A checker must test whether a "painting" is just a blurred reference played back in reverse order of sharpness. That is a defect class to add: Resolve-by-blur — end frame too close to the reference, with no real brush structure at fine sizes. Ananth denied the blur claim, but the test still belongs in the checker; denial is not proof.
4. Cost/time claim is a check, not a fact. Ananth says <1% quota, ~5 mins. No log, no bill, no frame count was shown. Do not copy that claim into a tool promise.
5. No easing to fit here. The easing/timing picker from the earlier X study does not apply to this clip. Fitting an ease curve to a timelapse would invent motion that is not there. Teardown must say "no camera/ease" explicitly, rather than defaulting to easeOutQuint.
6. UI labels are part of the style. The pass label ("PAINTING PASS • Block-in") and the brush-size toolbar are what make the process legible. A copy that drops them loses the story, even if the portrait matches.
